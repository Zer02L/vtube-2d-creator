# 2D VTuber Creator & Studio (`creator-2d-avatar`)

Современный кросс-платформенный инструмент для 2D VTuber'ов и PNGTuber'ов на базе **Tauri 2.0 (Rust) + Vue 3 + Tailwind CSS + FFmpeg**.

Поддерживает всеядный импорт любых видеоформатов, предварительное запекание зеленого хромакея в оптимизированный прозрачный **WebM VP9 (`yuva420p`)**, двухбуферный бесшовный видеоплеер без черных кадров, активацию по голосу (VAD) и нативный вывод в **OBS Studio (Browser Source)**.

---

## 🚀 Архитектурные особенности

1. **Бесшовный Dual-Player (Ping-Pong):**
   - Два скрытых параллельных видеоплеера, сменяющих друг друга на лету.
   - Устраняет разрывы анимации, микрофризы и черные кадры при переходе Покой ↔ Разговор ↔ Эмоция.
2. **Встроенный конвертер и Хромакей:**
   - Преобразование MOV (ProRes), MP4, GIF, WebM в стандартизированный формат с прозрачностью.
   - Интерактивная «Пипетка» для выбора цвета фона, настройка чувствительности (Similarity) и сглаживания (Blend).
   - Пресеты разрешений: `480p`, `720p`, `1080p` (дефолт), `2K`.
3. **Voice Activity Detection (VAD) на Rust:**
   - Высокоточный расчет среднеквадратичной амплитуды (RMS).
   - Настраиваемые фильтры **Attack** (задержка перед включением рта от случайных звуков) и **Hold/Decay** (удержание рта открытым в микропаузах речи).
4. **Интеграция с OBS Studio:**
   - Локальный HTTP/WebSocket сервер (`http://localhost:12345/avatar`) для источника браузера OBS.
   - Аппаратное декодирование на GPU с 0% нагрузки на экран стримера.
5. **Мультиоконность:**
   - Окно 1: Полнофункциональная панель управления стримера.
   - Окно 2: Плавающий прозрачный оверлей с поддержкой `click-through` поверх игр.

## 🛠️ Запуск и разработка

### Быстрый старт (веб-интерфейс и плеер):
```bash
npm install
npm run dev
```
Откройте [http://localhost:1420](http://localhost:1420) в браузере.

### Сборка фронтенда:
```bash
npm run build
```

### Запуск десктопного приложения через Tauri:
- **На NixOS:**
  ```bash
  nix-shell --run "npm run tauri dev"
  ```
- **На Ubuntu / Debian:**
  ```bash
  sudo apt install libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf ffmpeg
  npm run tauri dev
  ```
- **На Windows:**
  Убедитесь, что установлены `WebView2`, `Rust` и `ffmpeg` в PATH:
  ```bash
  npm run tauri dev
  ```
